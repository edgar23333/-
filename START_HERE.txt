微信自动定时发送助手 V15.0

首次运行
1. 双击 check_environment.bat，确认 All checks passed。
2. 双击 run_debug.bat。
3. 在“任务编辑”里输入目标名称，例如 张三 或 李四工作群，然后点“添加并编辑”。
4. 在“校准与核验”里分别设置搜索结果区域和聊天标题区域。两个步骤会先后进入，不会互相冲突。
5. 先使用“测试点击（只进入目标，不发送）”确认定位正确，再发送。

微信启动规则
- 已打开主界面：直接激活。
- 出现微信小登录窗口并且有“进入微信”：自动点击。
- 出现扫码登录：停止并提示手动扫码。
- 如果 Windows 搜索没有真正获得焦点，程序不会执行 Ctrl+V/Enter，避免误操作其他窗口。

预览规则
- “屏幕显示”：直接在当前桌面显示绿色框线，按 ESC 关闭。
- “截图查看”：打开微信客户区截图并显示框线。

EXE 打包
- 先关闭正在运行的 V15/WeChatAutoSender.exe。
- 双击 build_windows.bat。
- 成功后在 dist\WeChatAutoSender 里使用 WeChatAutoSender.exe；整个文件夹需要一起保留。
